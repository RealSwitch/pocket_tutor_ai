# **App Name**: Learnify

## Core Features:

- Personalized Learning Path: The application uses AI as a tool to analyze student performance and adaptively generate unique, randomized challenges based on their individual strengths and weaknesses.
- Gamified Mini-Games: Interactive mini-games and simulations to teach concepts instead of traditional lessons, providing immediate feedback through animations and progress tracking.
- Progress Tracking: A dashboard for students to view their progress, earned badges, and leaderboard rankings to encourage friendly competition.
- Adaptive Difficulty: The application dynamically adjusts the difficulty level of the content based on the student's performance, ensuring a personalized learning experience.
- Subject Modules: A core engine designed with plug-in modules for various subjects like Mathematics, Accounting, Geography, and more, each offering tailored mini-games and challenges.
- QR Code Rewards: Integrate a QR code system for students to redeem points/coins earned for real-world rewards (e.g., discounts at local stores).

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to evoke a sense of trust, intelligence, and forward-thinking in learning.
- Background color: Light blue (#E0F7FA) for a calm, non-distracting learning environment.
- Accent color: Yellow-orange (#F4D03F) to highlight important elements and encourage interaction.
- Body and headline font: 'PT Sans', a humanist sans-serif combining a modern look with warmth and personality, suitable for both headlines and body text.
- Use clear and intuitive icons that are consistent with the gamified and educational context of the app.
- Incorporate subtle, encouraging animations to enhance user engagement and provide visual feedback during interactions and learning activities.
- Design a clean, intuitive layout with a clear visual hierarchy, prioritizing ease of navigation and accessibility for students of all ages.
